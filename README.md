# Multimedia Writing Portfolio

Noah Boyd's portfolio for Multimedia Writing & Rhetoric at the University of Notre Dame. The site presents essays, visual work, a multimedia project, and reflections on sustainability, burnout, and AI.

## View locally

```sh
git clone https://github.com/3nboyd/Multimedia-Portfolio.git
cd Multimedia-Portfolio
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). This is a static HTML, CSS, and JavaScript site with no build step.

## Contents

- `index.html` presents the introduction, project sections, and contact area.
- `styles.css` and `script.js` provide the layout and interactions.
- [Final Portfolio PDFs](Final%20Portfolio%20PDFs/) contains the written pieces and multimedia transcript linked from the site.
- The multimedia video is linked through Google Drive; access depends on that file's sharing settings.

The original writing and project descriptions are presented on the site. See [LICENSE](LICENSE) for the repository's terms.
